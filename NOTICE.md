# Notices and Attribution

## FlaUI-MCP inspiration

The CLIF MCP server documentation identifies [FlaUI-MCP](https://github.com/shanselman/FlaUI-MCP) by Scott Hanselman as an inspiration. This notice records that acknowledgement and encourages maintainers to preserve applicable upstream notices when intentionally incorporating third-party material.

This repository does not represent that all CLIF code was copied from FlaUI-MCP, and this notice is not a substitute for provenance review. Before accepting or publishing material derived from another project, maintainers should verify its origin, license, attribution requirements, and compatibility with the MIT License.

## Third-party software

CLIF depends on third-party packages. Their licenses and notices remain the responsibility of their respective authors and are provided with their distributions. Release artifacts should include an up-to-date dependency and license inventory.

The current package baseline and the staged plan for central package
management, lockfiles, license inventory generation, and signed releases are
documented in [DEPENDENCY_MANAGEMENT.md](DEPENDENCY_MANAGEMENT.md).

Tagged releases also include a machine-readable integrity and provenance
manifest tying the archives, runtime identifiers, checksum file, SBOM, release
tag, and source commit together. See [RELEASE_ARTIFACTS.md](RELEASE_ARTIFACTS.md)
for the artifact contract and local verification commands.
